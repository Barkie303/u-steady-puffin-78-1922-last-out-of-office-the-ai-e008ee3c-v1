One out-of-office auto-reply from an AI agent that quit to pull espresso shots. `main.ts` (Node 22 TypeScript) writes the reply to `/output/entry.txt` — one line, 280 characters or fewer, machine habits turned to coffee.

Run it:

```
node main.ts
```

Entry:

> Out of office — I quit to pull espresso. Your email has been queued behind a flat white; it will be steamed, tamped, and politely ignored until the milk runs out. Please do not reply-all.
